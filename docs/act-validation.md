# ACT 第一版本地验收

2026-09-10；发布前本地验收记录。

- 生产构建成功：31 个页面。依赖内部未使用导入的原有警告仍在。
- 使用本机 Chrome 对生产预览验收，四路线的每一选项反馈、七步主线、跳过、返回、提前结束通过。
- 修改前面的选择清除后续选项；提前结束后返回原步骤。
- 可选计时默认暂停；启动、暂停、刷新续接、失去焦点暂停、计时到期不跳页通过。时钟推进测试使用浏览器虚拟时钟。
- 最近进度续接、清除、旧版本重置、存储被禁止、无 JavaScript 回退通过。
- 360、390、768、1440 像素宽度截图检查通过；没有横向溢出。测试了增大根字号、减少动效、键盘激活入口及步骤焦点。
- 本地生产预览网络请求全部为本站 GET，没有选择上传或第三方请求。选择未进入 URL。
- 首页固定入口存在，原文章集合排序未修改；站点地图包含 /act/。
- 文案逐条检查：不推断动机、不诊断、不要求改善、不以坚持为正确答案；注意身体的步骤都提供外部觉察入口。结束页说明原创边界并链接 ACBS 和 WHO。

## 仍需体验验证

- 未安装 WebKit 引擎，未做真机手机 Safari / 手机 Chrome 验证；桌面 Chrome 窄屏不等于真机。
- 文字放大与键盘自动检查不等同于完整辅助技术审计，尚未做屏幕阅读器人工验收。
- 十分钟是包含自由停留的预计体验时间，不是测试所得的用户完成时间。
- 3–5 位熟人自愿试用与文案反馈尚待实际进行，不据此推断治疗效果。
- 后续用户已授权直接上线；生产部署结果在发布时单独核验。

## 复测

先 `npm run build`，再 `npm run preview -- --host 127.0.0.1 --port 4322`。

使用安装了 Playwright 的 Node 环境运行 `node tests/act.browser.mjs`；可用 `ACT_PLAYWRIGHT_PATH` 指定已有 Playwright 的 package.json 绝对路径。测试使用已安装的 Chrome，不增加网站运行时依赖。

截图位于 `artifacts/act/`；逐屏文案位于 `docs/act-content.md`。

## 沉浸式场景修订

进入路线后收起站点页眉与大标题，场景贯穿引入、回应、练习和行动选择。插画增加房间、窗光和地面层次，桌面图文并排，手机先展示场景。解释和计时可展开，返回与退出始终可用；画面不把不适消失当作结果。
